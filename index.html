Inside Spartan ↗
Actual engine captures
  • +

    ReSTIR path tracing

    Spatiotemporal reservoir resampling for real-time multi-bounce global illumination. No bake step, no light probes.

  • +

    Zero-binding draw path

    All per-draw data sits in a single bindless storage buffer. Push constants carry an index and nothing else.

  • +

    Hardware ray tracing

    Ray-queried reflections and shadows sharing one vertex-pulling path with the rasteriser.
