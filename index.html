Spartan Engine

A bindless, GPU-driven engine with real-time path-traced global illumination

The full breakdown

Built around one principle: the GPU owns the data. Every resource — geometry, materials, textures, lights, transforms, bounding volumes — lives in persistent, globally accessible buffers. No per-draw descriptor updates. No CPU-side draw loops.

  • ReSTIR path tracing

    Spatiotemporal reservoir resampling for real-time multi-bounce global illumination. No bake step, no light probes.

  • Zero-binding draw path

    All per-draw data sits in a single bindless storage buffer. Push constants carry an index and nothing else.

  • Hardware ray tracing

    Ray-queried reflections and shadows sharing one vertex-pulling path with the rasteriser.

  • 200 Hz vehicle dynamics

    Pacejka MF 5.2 tyres with thermal, pressure and wear models, inside the PhysX fixed-timestep loop.

  • Vulkan and DirectX 12

    One universal HLSL codebase compiled to both SPIR-V and DXIL, from the same shaders.

  • Oceans, clouds and fog

    Tessendorf FFT ocean in compute, Nubis-style volumetric clouds, froxel volumetric fog with temporal reprojection.
