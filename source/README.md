# panoskarabelas.com

Personal site for [Panos Karabelas](https://panoskarabelas.com/).

Built with [Hugo](https://gohugo.io/) and the [Hermit-V2](https://github.com/1bl4z3r/hermit-V2) theme. Published via GitHub Pages from the repo root.

## Edit and preview

1. Open a terminal in `source/`
2. Run `run.bat` (starts local server at http://localhost:1313/)
3. Edit markdown under `content/`

## Publish

1. Run `build.bat` from `source/` (writes HTML to the repo root)
2. Commit and push `master`

Requires Hugo Extended **0.164.0** (`hugo_extended_0.164.0.exe` in this folder).
