How they are made

Read the original. Rebuild it natively.

  • 01

    Reverse engineered

    Each behaviour starts from the original game's code, read in Ghidra, so the port computes the same results rather than an approximation tuned by eye.

  • 02

    Native and readable

    No emulator. The recovered systems are rewritten as clean native code that runs on modern Windows, with keyboard, gamepad and display support.

  • 03

    Upgrades are a choice

    Visual improvements sit behind their own settings and a master switch, so the original look is always one toggle away.

  • 04

    Your own copy

    The ports read the game data from your own disc image. No original game files are distributed.
